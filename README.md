This Stream Deck plugin provides actions to interact with [VATSIM Radar](https://www.vatsim-radar.com/) running on your local machine.

[Read the documentation](https://projects.neilenns.com/docs/streamdeck-vatsim-radar) for information on how to set up actions.

Do you use TrackAudio or vATIS when controlling? Check out the [Stream Deck actions for TrackAudio](https://marketplace.elgato.com/product/trackaudio-e913a0ca-4c12-411d-a5a6-acf5f6c4bdea) and [Stream Deck actions for vATIS](https://marketplace.elgato.com/product/vatis-878fcd1a-7e0a-4d6e-bd36-c70b075573ea).
